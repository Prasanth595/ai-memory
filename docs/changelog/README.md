# Changelog archive

Released versions rotated out of the active [`CHANGELOG.md`](../CHANGELOG.md) live here as immutable markdown, one file per semver.

Contributors add entries only under `## [Unreleased]` in the root changelog. `bin/release` moves that block into a new version section and rotates older releases into this directory. See [CONTRIBUTING.md](../CONTRIBUTING.md) ("CHANGELOG is a merge gate").

To read an older release: open the file below, `git show vX.Y.Z`, or the matching [GitHub release](https://github.com/akitaonrails/ai-memory/releases).
